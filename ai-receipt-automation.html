1# AI Receipt Automation

Drop a receipt into a Google Drive folder and it files itself. Gemini reads the image, pulls out the vendor, date and total, learns the naming pattern you prefer, and renames the file into something searchable — no manual typing, no inconsistent file names, no folder left to tidy up later.

2# How It Works

  • 1 · Upload — snap or scan a receipt and drop it into the Drive folder.
  • 2 · Google Drive — the automation watches the folder and picks up every new file.
  • 3 · Gemini AI — reads vendor, date and total straight off the image, and learns how you like files named.
  • 4 · Auto-renamed — a clean, searchable name is applied and the file is filed away.

3# What Changes

A receipt arrives from a phone camera as something like IMG_4521.jpg — no context, impossible to find later. It leaves as 2026-11-25_Starbucks_12.40.jpg, with the date, vendor and amount built into the name, filed into a year and month folder.

Because the date leads the filename, receipts sort chronologically on their own, and searching for a vendor or an amount finds the file without opening anything.

4# Learning the Pattern

The naming convention is not hardcoded. Gemini picks up how you already name files and follows that pattern, so the automation fits an existing filing system rather than forcing a new one. It is set up once and then runs on every receipt that lands in the folder.

5# Why It Matters

  • No manual renaming or data entry for expense receipts.
  • Consistent, searchable filenames across every vendor.
  • Receipts filed into date-based folders automatically.
  • Expense records stay ready for bookkeeping and tax time.
